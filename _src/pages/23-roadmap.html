Analytics and reporting

Revenue, commission, clicks and conversions over selectable periods, per-partner league tables, and day-by-day charts that include the quiet days. Closed days come from nightly rollups; today is computed live from the same arithmetic. Days close in your organization’s timezone, not the server’s.

Architecture, not features

The data model accommodates these. That is not the same as having them.

Refficks is described as a Partner Growth OS, and the schema was built for more than affiliates. But the affiliate module is what ships, and an architecture is not a feature you can run a programme on.

Architecture only

Referral · creator · ambassador · agency · reseller

These programme types exist in the way the system is structured. They do not exist as things you can switch on, configure, and put partners into today.

So we do not sell them, we do not put them on the home page, and if you are evaluating Refficks for a creator programme rather than an affiliate one, the honest answer is: not yet, and we are not going to tell you a quarter.

Precisely: if you are building against the API, do not design around these. Build against what is documented in the OpenAPI specification that ships in the repository.

Not built

Named, so you can rule us out quickly

If one of these is a hard requirement, Refficks is not the right tool for you right now, and it is cheaper for both of us if you find that out on this page.

Payment integrations beyond Stripe

Planned, not present

Stripe is the payment integration today, alongside the generic REST API and the JavaScript tracker — which between them cover most stacks. Paddle and others are planned. There is no date, and we will not invent one.

A hosted version

Not built

Refficks is self-hosted only. There is no cloud version, no trial environment we run for you, and no migration path from one to the other, because there is nothing to migrate to.

You can leave an email address if you want to hear about a hosted version. That is an interest list, not a waitlist with a launch behind it.

Compliance certifications

None held

Refficks holds no compliance certifications, and we are not going to name one we are “working towards” as though that were the same thing.

What exists instead are practices you can verify in the code you are running: multi-tenant isolation with a test on every resource, append-only events, attributions, commission entries and audit logs, no raw IP addresses stored anywhere, and payout details encrypted at rest and never displayed back.

Precisely: if your procurement process requires a certification, that is a legitimate requirement and Refficks does not meet it today.

An open-source license

Not chosen

A license has not been chosen. Until one has been, Refficks is self-hosted software and we will not describe it as open source — those are different promises, and the second one is not ours to make yet.

Uptime commitments, customer references, usage numbers

None exist

There is no uptime SLA, there are no named customers, and there are no usage statistics — because there are none yet, not because we are keeping them quiet.

This is an early product. The substitute for proof we do not have is a product that shows its reasoning on every screen, and a list like this one.

The dating policy

Why nothing on this page has a quarter beside it

A dated roadmap from an early product is a forecast dressed as a commitment. It gets quoted back in procurement, it gets planned around, and when it slips — and it slips — the cost lands on the person who believed it.

So this page tells you the state of each thing and nothing about when. If that makes Refficks harder to buy today, that is the correct outcome: you should buy it for what it does now.

Refuses to

Put a date on a roadmap

Every item here is in one of three states: shipping, architecture only, or not built. Those states change when the software changes, and this page changes with them.

Precisely: the same rule the product follows on screen — no confident zeroes, no invented comparisons — applied to the marketing. A date we have not earned is a number we have not earned.
