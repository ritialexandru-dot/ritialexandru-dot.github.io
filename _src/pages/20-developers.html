amount is integer minor units and currency is an ISO code, everywhere in the API. 29900 is USD 299.00. There are no floats and no silent conversions between currencies.

Idempotency

Retries are free. Duplicates are structurally impossible.

Send that request again and you get the original result back. Not a second commission, not a 409 you have to write handling for — the original.

This matters because your retry logic is going to fire. A queue will redeliver. A webhook will time out after the write succeeded. Somebody will double-click a button. In each case the second attempt resolves to the first.

Precisely: idempotency is enforced by the database, not by an application-level check that races under concurrency.

What that buys you

  • No reconciliation job. You do not need a nightly script that hunts for duplicate commissions.
  • No exactly-once queue. At-least-once delivery is sufficient, which is the only kind you actually have.
  • No coordination. Two workers can process the same message and the ledger still holds one entry.

The data model promise

Every number can explain itself

One append-only chain runs from the raw payload you sent to the money you owe. Each link keeps its own reasoning, so no figure ever has to be recomputed in order to be justified.

integration_eventThe raw payload exactly as it arrived, before anything interpreted it.
→
eventThe normalised click or sale, deduplicated by the database.
→
attributionWhich partner won, which lost, why, and a confidence score.
→
commission_entryThe amount, plus the arithmetic that produced it.

Append-only, all four

Events, attributions, commission entries and audit logs are append-only. A refund writes a reversal beside the original. A correction supersedes; it does not overwrite.

The audit log has before and after

Who did what, when, with the values on both sides of the change. “Who moved this partner to 25%?” is a query, not an investigation.

Reasoning is stored, not derived

The Attribution Debugger reads a record written at decision time. It does not re-run today’s rules against last quarter’s data and call the result an explanation.

Multi-tenancy

Isolation is a tested property

Not a convention, not a code-review rule, not a middleware someone remembered to add. Every resource carries a test proving one organization cannot read another’s data.

You can run that suite yourself before you put a single real partner in.

Precisely: a new resource without an isolation test is a failing build, which is the only version of this guarantee worth anything.

Self-hosting

DNS to signed-in in under an hour

Three commands on a fresh server. HTTPS is included automatically, so there is no certificate step and no reverse-proxy afternoon.

Hardware, honestly: 2 vCPU and 4 GB of RAM is comfortable. This is a Laravel application with MySQL and Redis behind it, not a cluster.

Precisely: your database is your database. There is no phone-home, no shared control plane, and no tenant of ours in it.
