Privacy

Nothing to consent to

This page describes what refficks.com collects. It is short because the answer is close to nothing.

Review with counsel before publishing. This is a plain-language draft written to describe what the site actually does. It has not been reviewed by a lawyer, and it is not legal advice. Your jurisdiction may require disclosures that are not here.

The short version

  • No cookies are set by this website. There is no consent banner because there is nothing to consent to.
  • No third-party trackers, advertising pixels or session recorders are loaded.
  • No web fonts are fetched from another company. The site uses the fonts already on your device.
  • The only data you can give this site is an email address, and only if you choose to type one into the hosted-version interest form.

Why the site works this way

The product itself never stores a raw IP address — fraud signals run on salted hashes — and it respects Do Not Track by default. It would be incoherent to run a marketing site that collected more about you than the software it is selling.

If analytics are added later, they will be cookieless and privacy-first, of the kind that does not identify individual visitors and does not require a consent banner. If that ever changes, this page changes first.

The interest form

The early access page has one field: an email address. If you submit it, that address is used to tell you about a hosted version of Refficks and nothing else. No newsletter, no sequence, no sharing it with anyone.

Ask and it is deleted. There is no account to close and no export to request, because an email address is the whole record.

Server logs

This site is served as static files by a hosting provider, which keeps standard access logs of the kind every web server keeps. Refficks does not analyse those logs to profile visitors.

What this page does not cover

Refficks is self-hosted software. When you run it, the partner data, click data and payment data live in a database on infrastructure you control. Refficks has no copy of it and no access to it.

That also means the privacy notice your own partners and customers need is yours to write, about your deployment. This page cannot do that job for you, and it does not try to.

Links away from here

Signing in or starting an account takes you to app.refficks.com, which is the product rather than this website. What that application collects is described where you sign up for it.

Getting in touch

Questions about this page, or a request to delete an email address you submitted, should go to the address published in the repository.
