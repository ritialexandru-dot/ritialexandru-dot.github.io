# ritialexandru-dot.github.io

The marketing site for Refficks (refficks.com) is planned here. Nothing is
built yet.

Two documents in the product repository decide what gets built:

- `refficks/docs/website-prompt.md` — the build brief: positioning, voice, the
  fact sheet every claim must trace to, and the launch pages.
- `refficks/docs/website-information-architecture.md` — the full site map in
  three phases, who each page serves, where each resource lives, and how
  visitors move between pages.
